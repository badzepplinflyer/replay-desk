# Replay Desk

Capture and clip your moments. Replay Desk keeps an instant replay buffer, records your games, and lets you trim clips and build compilations. Windows 10 and 11.

**Website:** [getreplaydesk.com](https://getreplaydesk.com)
**Download:** [ReplayDesk-Setup.exe](https://github.com/badzepplinflyer/replay-desk/releases/latest/download/ReplayDesk-Setup.exe)

Free for 14 days, then a one-time lifetime license. Installers and update notes are under [Releases](https://github.com/badzepplinflyer/replay-desk/releases).

If Windows shows **"Windows protected your PC"**, click **More info → Run anyway**. The app isn't code-signed yet, so you'll see that once.

Help: [support@getreplaydesk.com](mailto:support@getreplaydesk.com)

This repository hosts the website (`docs/`) and the release downloads.
